# Yiang — Future Innovation Studio

Public website repository: https://yiang1905.github.io/Yiang/

## Site structure
- `index.html` — bilingual studio homepage and project portfolio
- `style.css` — responsive visual system
- `script.js` — language switch, mobile navigation and email-copy interaction
- `image/` — locally hosted visual assets
- `robots.txt`, `sitemap.xml`, `404.html` — basic search and navigation support
- `Yiang-Health` is maintained as a separate repository/site and linked from the main site; it is not embedded or merged here.

## Publishing
The site is a static GitHub Pages website. No build step, package install, analytics script or third-party form service is required. Commit only the intended public website files when publishing. Keep internal workspaces, backups, credentials, drafts and private project material out of the public repository.

## Content accuracy
- NeuroSleep is described as a concept / strategic-development project; no commercial hardware prototype or clinical validation is claimed.
- Yiang Health is described as a China-focused wellness and cultural experience information platform, not a medical diagnosis service.
- Yiang Office AI is described as product research / MVP planning, not as a launched product.
- YiangLab services are described as AI-assisted work with human review; scope and delivery are agreed before work begins.
